          human_confirmed: 16건 전부 False — 아직 아무도 실물확인 안 함

### 반드시 지킬 것

1. **서버는 `debug=False`라 코드를 고쳐도 자동 반영 안 됨.** 코드 수정 후 `pkill -f "webapp/app.py"` → 재실행 → 브라우저로 직접 확인.
2. **`git push`는 매번 확인받고 진행.**
3. **"실물확인 완료"는 사람만 누를 것.** 1단계에서 만든 게이트라 Claude가 대신 클릭하면 안전장치의 의미가 없어진다 — 후보 사진을 실제로 보고 판단하는 게 이 게이트의 존재 이유.
4. 설명은 사업 언어로. 파일 경로·함수명 나열 금지(사용자에게 보고할 때).
5. 결과물은 크롬에서 열 수 있는 링크(`http://127.0.0.1:5050/...`)로 남길 것.

## 2. 보류된 것 — 전부 사용자 계정/시스템 설정 필요, Claude가 대신 못 함

**5단계 나머지 3건** (사용자가 명시적으로 "전부 나중에"로 보류):
1. **주기 실행(crontab) 등록** — 코드는 준비됐음(`main.py sync --apply`, `main.py purchase queue`, `main.py purchase sync-tracking`, `main.py tracker sync`). 실제 crontab 등록만 하면 됨.
2. **카카오 "나에게 보내기" 알림 설정** — `python3 main.py notify setup` 실행 필요. developers.kakao.com에서 앱 생성 후 REST API 키 발급 → `.env`의 `KAKAO_REST_API_KEY` 채우기 → OAuth 1회 인증.

4. **기등록 2건(실리콘주걱/우산) 스마트스토어센터에서 수동 삭제** — 삭제 완료 후 `data/registered_products.json`을 비울 것(파일 자체는 로컬 전용, gitignore 대상이라 지금 2건이 그대로 남아 있음).
